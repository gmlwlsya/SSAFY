2. **df.clip()**
    :`DataFrame.clip()` 또는 `Series.clip()`은 데이터의 최솟값과 최댓값 범위를 제한(임계값 설정)하는 메서드입니다.

      * **기능**: 지정한 범위(`lower`, `upper`)를 벗어나는 이상치(Outlier)나 극단값을 설정한 임계값으로 잘라냅니다.
      * **동작 방식**: 최솟값보다 작은 값은 `lower` 값으로, 최댓값보다 큰 값은 `upper` 값으로 각각 대체됩니다.
      * **핵심 파라미터**: `lower` (하한선 지정), `upper` (상한선 지정), `inplace=True` (원본 변경).
      * **사용 예시**: `df['수량'].clip(lower=0, upper=100)` $\rightarrow$ 0 미만은 0으로, 100 초과는 100으로 보정.

5. **cut, qcut**
    >Pandas의 `pd.cut()`과 `pd.qcut()`은 연속형 수치 데이터를 구간(Bin)으로 나누어 **범주형(Categorical) 데이터**로 변환할 때 사용하는 대표적인 함수입니다.

    <br>

    1) **`pd.cut()`**: 동일한 폭(등간격)으로 나누기
    <br>

   - 데이터의 **최소부터 최대 구간의 길이(폭)를 동일하게** 나누어 범주화합니다.
    각 구간에 들어가는 **데이터의 개수는 서로 다를 수 있습니다.**

    * **주요 용도**: 점수 구간별 등급(A, B, C...) 나누기, 나이대(10대, 20대...) 구분하기
    <br>

    ```python
    import pandas as pd

    scores = pd.Series([10, 25, 40, 55, 70, 85, 90, 100])

    # 0~100 구간을 동일한 폭으로 3개 구간 나누기
    result = pd.cut(scores, bins=3, labels=['하', '중', '상'])

    print(result)

    ```
    결과 설명

    * 구간 폭: 약 30점 단위로 동일하게 분할 (`(9.91, 40.0]`, `(40.0, 70.0]`, `(70.0, 100.0]`)
    * 데이터 분포와 상관없이 **구간의 길이**가 동일합니다.
    <br>
    ---

    2) **`pd.qcut()`**: 동일한 개수(분위수)로 나누기

    - 데이터를 크기순으로 정렬한 뒤, 각 구간에 들어가는 **데이터의 개수가 거의 같도록** 나누어 범주화합니다. (Quantile-based cut)
    각 구간의 **폭(길이)은 서로 다를 수 있습니다.**

    * **주요 용도**: 고객 분위수(상위 20%, 중위 20% 등) 나누기, 데이터 편향이 심할 때 균등한 샘플 그룹화

    <br>

    ```python
    import pandas as pd

    # 데이터가 한쪽으로 쏠려 있는 경우
    sales = pd.Series([10, 12, 15, 18, 20, 22, 100, 500])

    # 데이터 개수가 같도록 4개 구간(사분위수)으로 나누기
    result = pd.qcut(sales, q=4, labels=['Q1', 'Q2', 'Q3', 'Q4'])

    print(result)
    print(result.value_counts())  # 각 구간별 데이터 개수 확인
    ```
    <br>

    결과 설명:

    * 각 구간마다 데이터가 **정확히 2개씩** 들어가도록 구간 분할.
    * 값의 편차가 커도 데이터 개수를 균등하게 나눕니다.

    <br>
    <br>

    **한눈에 비교하기**

    | 구분 | `pd.cut()` | `pd.qcut()` |
    | --- | --- | --- |
    | **분할 기준** | **구간의 폭(전체 길이 / n)**이 동일 | **구간 안의 데이터 개수**가 동일 |
    | **특징** | 값의 범위 기반 (Absolute Values) | 순위 및 분위수 기반 (Percentiles) |
    | **이상치 영향** | 극단값에 의해 구간이 비어버릴 수 있음 | 데이터 개수 기준이라 극단값 영향이 적음 |
    | **주요 파라미터** | `bins` (구간 수 또는 경계값 리스트) | `q` (분위수 개수) |

    > **Tip**: 라벨을 지정하고 싶을 때는 두 함수 모두 `labels=['GroupA', 'GroupB', ...]` 매개변수를 지정하면 됩니다.

7. 2개 이상의 값 할당 시 출력값

    >1. child 의 age 최솟값과 최댓값을 child나이 에 할당해 주세요.
    child나이 = titanic.loc[titanic["who"] == "child", "age"].agg(["min", "max"])
    이렇게 할당을 할 경우, child나이에는 min 값과 max값 중에 임의로 할당되는 건가?
<br>

아닙니다! 임의(랜덤)로 둘 중 하나가 선택되어 할당되는 것이 아닙니다.

`child나이`에는 **`min`과 `max` 두 가지 결과값이 모두 담긴 Pandas의 `Series` 객체**가 할당됩니다.
<br>

**실제로 할당되는 값의 구조**

위 코드를 실행하면 `child나이`는 단일 숫자가 아니라 다음과 같은 **인덱스가 있는 Series** 형태가 됩니다.

```python
print(child나이)

```

**[출력 결과 예시]**

```text
min     0.42
max    15.00
Name: age, dtype: float64

```

* `child나이["min"]` $\rightarrow$ 최솟값인 `0.42` 출력
* `child나이["max"]` $\rightarrow$ 최댓값인 `15.0` 출력

즉, 하나의 변수 안에 두 값이 인덱스 이름(`min`, `max`)을 달고 함께 들어간 것입니다.
<br>

**최솟값과 최댓값을 각각 단일 변수로 받으려면?**

만약 두 개의 변수에 각각 최솟값과 최댓값을 나누어 담고 싶다면 아래 방법 중 하나를 사용하는 것이 좋습니다.

- 방법 A: 언패킹(Unpacking) 활용

```python
# 순서대로 min, max 값이 각각의 변수에 할당됩니다.
child_min, child_max = titanic.loc[titanic["who"] == "child", "age"].agg(["min", "max"])

```
<br>

- 방법 B: `.min()`, `.max()` 각각 호출

```python
child_age = titanic.loc[titanic["who"] == "child", "age"]

child_min = child_age.min()
child_max = child_age.max()

```

## 📌 1. 단어 임베딩 (Word Embedding)

### 1-1. 원-핫 인코딩 (One-Hot Encoding)

* **개념**: 단어를 쪼갤 수 없는 기호로 보고, 단어 사전 크기의 벡터에서 해당 단어 위치만 `1`, 나머지는 `0`으로 표현하는 방식
* **한계점**:
* **고차원 희소 행렬 (Sparse Matrix)**: 단어 사전이 커질수록 메모리 낭비 심화
* **직교성 (Orthogonality)**: 모든 단어 벡터 간 내적이 0이 되어 **유사도 및 맥락을 측정할 수 없음**



### 1-2. 워드 임베딩 & Word2Vec

* **개념**: 단어를 저차원의 밀집/연속적 벡터(Dense Vector)로 변환하여 의미적 유사성을 공간상 거리에 반영
* **Word2Vec의 두 알고리즘**:
* **CBOW (Continuous Bag of Words)**: 주변 단어(Context)들을 입력받아 중심 단어(Target)를 예측
* **Skip-gram**: 중심 단어 1개를 입력받아 **주변 단어들**이 나올 확률 분포를 예측 (학습량은 많으나 상대적 성능 우수)



> **💡 Word2Vec의 인코더/디코더 역할**
> * **인코더**: 고차원 단어 데이터를 저차원 밀집 벡터(의미 공간)로 압축
> * **디코더**: 압축된 의미 벡터를 바탕으로 타겟 단어의 확률 분포를 복원/예측

## 📌 2. 순환 신경망 (RNN & LSTM)

### 2-1. 순차적 데이터 (Sequential Data)의 특징

1. **순서 의존성**: 단어 순서가 바뀌면 문장 의미가 변경됨
2. **장기 의존성 (Long-Term Dependency)**: 멀리 떨어진 과거 정보가 현재 예측에 영향을 미침
3. **가변 길이 (Variable Length)**: 입력 및 출력의 길이가 일정하지 않음

### 2-2. RNN (Recurrent Neural Network)

* **동작 방식**: 이전 시점의 은닉 상태($h_{t-1}$)와 현재 입력($x_t$)을 받아 새로운 은닉 상태($h_t$)를 계산
* **핵심 수식**:

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$$


* $h_t$: 현재 시점의 기억 상태 (Hidden State)
* $\tanh$: 가중치 폭발을 막고 $-1 \sim 1$ 사이로 압축하는 비선형 활성화 함수
* $W_{hh}, W_{xh}$: 모든 시점에서 **파라미터 공유 (Parameter Sharing)**


* **한계**: 시퀀스가 길어질수록 역전파 기울기가 사라지는 **기울기 소실(Vanishing Gradient)** 발생

### 2-3. LSTM (Long Short-Term Memory)

* **핵심 아이디어**: 장기 기억 통로인 Cell State ($C_t$)를 별도로 두어 기울기 소실 문제 해결
* **3가지 핵심 게이트**:
1. **Forget Gate ($f_t$)**: 과거 정보를 얼마나 잊을지 결정 ($\sigma$)
2. **Input Gate ($i_t$)**: 새로 들어온 정보를 얼마나 저장할지 결정 ($\sigma$)
3. **Output Gate ($o_t$)**: 업데이트된 $C_t$ 중 외부에 얼마나 내보낼지 결정 ($\sigma$)


* *참고: $C_t$는 내부에만 흐르며, 최종 출력값은 $C_t$에 $\tanh$를 취하고 $o_t$와 곱해진 $h_t$(Short-term)입니다.*

## 📌 3. Seq2Seq & Attention Mechanism

### 3-1. Seq2Seq (Sequence-to-Sequence)

* **구조**: **Encoder**(입력을 고정 크기 Context Vector로 압축) + **Decoder**(Context Vector를 받아 출력 시퀀스 생성)
* **추론 및 학습 기법**:
* **Teacher Forcing**: 학습 단계에서 디코더의 입력으로 이전 예측값이 아닌 실제 정답(Ground Truth)을 주어 학습 안정화
* **Beam Search**: 인퍼런스 시 매 단계 상위 $k$개의 최적 후보 조합만 유지하여 탐색 효율 향상 (Greedy Search의 한계 보완)


* **한계 (Bottleneck Problem)**: 모든 정보가 하나의 고정된 벡터로 압축되므로 문장이 길어지면 정보 손실 발생

### 3-2. Attention Mechanism

* **개념**: 디코더가 매 타임스텝마다 인코더의 모든 Hidden State 중 필요한 부분에 가중치를 부여(집중)하여 참조
* **작동 수식 요약**:
1. 디코더 상태($s_i$)와 인코더 상태($h_j$)의 유사도(Score) 계산
2. Softmax를 취해 어텐션 가중치($\alpha_{i,j}$) 변환
3. 인코더 상태들의 가중합인 **Context Vector ($c_i$)** 생성 후 디코더 예측에 활용


* **장점**: 병목 현상 제거, 기울기 소실 완화, 모델 해석 가능성 향상

## 📌 4. 트랜스포머 (Transformer)

### 4-1. Self-Attention (Scaled Dot-Product Attention)

* **개념**: RNN 구조 없이, **문장 내부의 단어끼리** 직접 연관성을 계산하는 메커니즘 ($O(1)$ 연산으로 병렬 처리 가능)
* **Q, K, V (Query, Key, Value) 역할**:
* **Query (Q)**: 기준이 되는 단어 (무엇을 찾을 것인가?)
* **Key (K)**: 대상 단어의 식별자 (어떤 단어와 관련이 있는가?)
* **Value (V)**: 대상 단어가 가진 정보의 실제 값


* **수식**:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$


* $\sqrt{d_k}$로 나누는 이유: 차원이 커짐에 따라 내적 값이 커져 Softmax 기울기가 소실되는 것을 방지 (Scaling)



### 4-2. Self-Attention의 한계 극복 기술

1. **Positional Encoding**: 순서 정보가 없는 Self-Attention을 위해 위치 벡터(Sin/Cos 함수 등)를 기존 임베딩에 더해줌
2. **Feed-Forward Network (FFN)**: 선형 결합인 Attention에 비선형 활성화 함수를 더해 표현력 증대
3. **Masked Self-Attention**: 디코더 학습 시 아직 생성되지 않은 미래 단어를 참조하지 못하도록 Masking 처리 ($-\infty$ 부여)
4. **Multi-Head Attention**: Q, K, V를 여러 개(Head)로 나누어 병렬로 어텐션을 수행함으로써 다각도의 문맥 관계 포착

## 📌 5. 사전 학습 기반 언어 모델 (Pretrained Language Models)

### 5-1. 사전 학습 (Pretraining)의 개념

대규모 말뭉치(Corpus)를 활용해 비지도/자가지도 학습(Self-Supervised Learning) 방식으로 일반적인 언어 패턴, 문맥, 지식을 미리 학습하는 과정

### 5-2. 대표 모델 유형 비교

| 구분 | **Encoder 기반 (BERT)** | **Encoder-Decoder 기반 (T5)** | **Decoder 기반 (GPT)** |
| --- | --- | --- | --- |
| **문맥 참조 방식** | 양방향 (Bi-directional) | 입력을 읽는 양방향 인코더 + 단방향 디코더 | 단방향 (Causal / Auto-regressive) |
| **주요 학습 과제** | MLM (Masked Language Model) | Text-to-Text 통일 프레임워크 | Next Token Prediction |
| **주요 활용** | 문장 분류, 감정 분석, NER | 번역, 요약, 문장 변환 | 자연어 생성, 대화, 종합 추론 |
| **적용 방식** | Fine-tuning 중심 | Fine-tuning / Text Prefix | **In-Context Learning (Prompting)** |

> **💡 참고 사항**
> * **BERT의 NSP(Next Sentence Prediction)**: 초기 BERT 학습에 도입되었으나, 이후 RoBERTa 등의 연구에서 성능에 미치는 영향이 미비함이 밝혀져 최근에는 생략하거나 다른 과제로 대체하는 추세입니다.
> * **개체명 인식 (NER) BIO 태깅**: **B**(Begin, 개체 시작), **I**(Inside, 개체 내부), **O**(Outside, 개체 아님)로 구분합니다.

### 5-3. In-Context Learning (ICL) & Prompting

* **개념**: 가중치(Weight) 파라미터 업데이트 없이, 입력 프롬프트 내 지시문과 예시(Context)만으로 작업을 수행하게 만드는 기법
* **Shot 구분**:
* **Zero-shot**: 예시 없이 지시문만 제공
* **One-shot / Few-shot**: 1개 또는 2~3개 이상의 정답 예시를 함께 제공


* **추론 능력 향상 프롬프팅 기법**:
* **CoT (Chain-of-Thought)**: 예시 제공 시 "질문 $\rightarrow$ **중간 추론 과정** $\rightarrow$ 정답" 단계를 포함하여 논리적 추론 능력 도출
* **Zero-shot CoT**: 예시 없이 질문 뒤에 "Let's think step by step"이라는 문구만 추가하여 모델의 단계별 사고 유도

# git
## 같은 원본 파일의 다른 커밋 상태 충돌 방지

### 이전 파일과 새로 정리한 파일을 원하는 부분만 merge 하고 싶어요
- 15일에 스터디하고 분명히 commit 습관처럼 했다고 생각하고 한치의 의심도 없었는데 오늘 멀캠에서 pull 받고 정리 전 상태인 정리본을 봤을 때의 기분을 서술하시오....
- 우선 정확히 어디까지 세세하게 정리했는지 기억이 안나서 앞부분은 복붙하기로 하고 기억에 남은 거의 끝부분부터 이어 했음. 
- 다행히도 얼마 차이 나지 않아 정말 다행이었다.... 이제 여기서 문제 어떻게 pull은 받아오면서 이전 내용은 잊지 않을 수 있을까?
#### 로컬 작업 내용을 잠시 보관하고 pull 하기 (추천 ⭐️)
~~~python
    # 1. 수정 중인 작업 임시 저장(스태시)
    git stash

    # 2. 원격 저장소 최신 코드 pull
    git pull origin master

    # 3. 임시 저장해둔 내 작업 다시 불러오기
    git stash pop
~~~

- 참고: git stash pop 과정에서 만약 같은 줄이 수정되었다면 **Merge Conflict(충돌)**가 발생할 수 있습니다. 이때는 해당 파일을 열어 충돌 부분을 정리한 뒤 커밋하시면 됩니다.

### 원하는 버전 파일 선택하기
* **왼쪽(빨간색 영역):** 기존에 있던 내용(삭제될 예정이거나 내 로컬 파일 내용)
* **오른쪽(초록색 영역):** 새롭게 들어온 내용(추가될 예정이거나 원격/상대방 파일 내용)


1. 상단 클릭 버튼으로 선택하기 (가장 쉬운 방법)
    에디터 상단(또는 충돌 영역 바로 위)에 표시되는 버튼을 클릭하여 선택할 수 있습니다.

    * **Accept Current Change (현재 변경 사항 수용):** 내 로컬/기존 버전(왼쪽)을 선택합니다.
    * **Accept Incoming Change (수신 변경 사항 수용):** 새로 가져온 버전(오른쪽)을 선택합니다.
    * **Accept Both Changes (두 변경 사항 모두 수용):** 두 내용을 모두 남깁니다.

2. 직접 에디터에서 편집하기
    1. 화면에서 원치 않는 쪽의 텍스트를 **직접 지우거나 필요한 부분만 복사·붙여넣기**합니다.
    2. 예시:
    * 맨 위 주석(`sidebar: true` 등)이 필요하다면 왼쪽에서 해당 텍스트를 남겨둡니다.
    * 필요 없는 부분은 일반 텍스트 편집하듯이 드래그해서 삭제하면 됩니다.


3. 최종 저장하기
    1. 원하는 대로 내용을 정리한 후, 키보드 단축키를 눌러 저장합니다.
    * **Mac:** `Cmd + S`
    * **Windows/Linux:** `Ctrl + S`

    2. 파일 이름 옆의 동그라미(수정됨 표시)가 사라지며 저장 완료됩니다.
<br>

4. Git 명령어로 처리해야 하는 경우 (Diff/Merge 상황일 때) 2가지
- 방법1
    ```bash
    # 1. 정리한 파일을 스테이징에 추가
    git add AI/03_2-1.자연어처리_기본.md

    # 2. 병합 완료 커밋
    git commit -m "fix: resolve merge conflict"

    ```

- 방법2: 터미널 명령어로 깔끔하게 가져오기

    ```bash
    # `git checkout`으로 원격(origin) 파일로 덮어쓰기
    git checkout origin/master -- AI/03_2-1.자연어처리_기본.md
    ```

    ```bash
    # 커밋 및 pull 완료하기
    git add AI/03_2-1.자연어처리_기본.md
    git pull origin master
    ```ㄴ

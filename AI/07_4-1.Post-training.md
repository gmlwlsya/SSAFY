<details><summary>목적 함수와 강화학습에서의 활용</summary>

수식은 **RLHF(인간 피드백 기반 강화학습)의 핵심인 목적 함수(Objective Function)** 로, **모델이 인간의 선호도에 부합하는 응답을 생성하도록 정량화** 한 수식입니다.

**1. 수식의 정의 및 변수 설명**

$$\mathbb{E}_{\hat{y} \sim p_{\theta}(y\vert{}x)} [R(x, \hat{y})]$$

  * **$x$ (Prompt/Instruction)**: 입력으로 들어오는 지시문 또는 질문입니다. (예: 요약할 뉴스 기사 본문)
  * **$\hat{y}$ (Generated Output)**: 언어모델이 주어진 $x$를 보고 생성해낸 응답/요약문입니다.
  * **$p_{\theta}(y\vert{}x)$ (Policy/Model Probability)**: 파라미터 $\theta$를 가진 언어모델이 입력 $x$에 대해 응답 $y$를 생성할 확률 분포(강화학습의 **Policy** 역할)입니다.
  * **$R(x, \hat{y})$ (Reward Function)**: 입력 $x$와 모델의 응답 $\hat{y}$가 주어졌을 때, 해당 응답이 얼마나 잘되었는지 평가하여 부여하는 보상 점수(실수값 $\mathbb{R}$)입니다.
  * **$\mathbb{E}_{\hat{y} \sim p_{\theta}}$ (Expected Value)**: 모델 분포 $p_{\theta}$에서 나올 수 있는 다양한 응답들에 대한 기대 보상(Expected Reward)을 의미합니다.


**2. 예시를 통한 이해**
  * **입력 ($x$)**: "샌프란시스코, 캘리포니아 (CNN) -- 규모 4.2의 지진이 샌프란시스코를 강타했습니다... 불안정한 물체가 넘어질 수 있습니다."
  * **응답 1 ($\hat{y}_1$)**: "샌프란시스코에서 지진이 발생했습니다. 재산 피해는 경미했으며, 부상자는 없었습니다."
  * **보상 ($R(x, y_1)$)**: **8.0** (핵심 내용을 정확히 요약했으므로 높은 점수)


  * **응답 2 ($\hat{y}_2$)**: "베이 지역은 날씨가 좋지만 지진과 산불에 취약합니다."
  * **보상 ($R(x, y_2)$)**: **1.2** (본문과 무관하거나 중요하지 않은 내용이 포함되어 낮은 점수)

목표는 모델의 파라미터 $\theta$를 업데이트하여, 점수가 1.2점에 불과한 $y_2$ 같은 응답 대신 8.0점 이상을 받을 수 있는 $y_1$ 같은 응답을 생성할 확률 $p_{\theta}(y_1\vert{}x)$을 계속 올리는 것입니다.

**3. 이게 어떻게 '강화학습(Reinforcement Learning)'이 되는가?**

강화학습은 상태(State) $\rightarrow$ 행동(Action) $\rightarrow$ 보상(Reward) $\rightarrow$ 정책 업데이트(Policy Update)의 순환 구조로 이루어집니다. 언어모델을 여기에 매핑하면 다음과 같습니다.

  * **환경 및 상태 (State)**: 입력 지시문 $x$ 및 지금까지 생성된 단어들
  * **행동 (Action)**: 다음에 생성할 단어(또는 완성된 문장 $\hat{y}$)
  * **정책 (Policy, $p_{\theta}$)**: 입력 $x$가 주어졌을 때 문장 $\hat{y}$를 출력하도록 동작하는 **언어모델 자체**
  * **보상 (Reward, $R$)**: 인간의 선호도가 반영된 보상 모델(Reward Model)이 매긴 점수

**강화학습 진행 과정 (Policy Gradient / PPO 알고리즘 활용)**:

  1. **탐색 (Sampling)**: 모델($p_{\theta}$)에 지시문 $x$를 입력하여 무작위 요약문 $\hat{y}$를 생성합니다.
  2. **보상 측정 (Feedback)**: 미리 학습시켜 둔 보상 모델 $R$에 $(x, \hat{y})$를 넣어 보상 점수 $R(x, \hat{y})$를 받습니다.
  3. **경사하향/상승법을 통한 업데이트 (Update)**:
  * 높은 보상($R$이 높음)을 받은 문장은 **발생 확률 $p_{\theta}(\hat{y}\vert{}x)$을 늘리도록** 파라미터 $\theta$를 가중 업데이트합니다.
  * 낮은 보상($R$이 낮음)을 받은 문장은 **발생 확률 $p_{\theta}(\hat{y}\vert{}x)$을 줄이도록** 조절합니다.

결과적으로 모델은 정답 텍스트(Ground Truth)를 직접 사람이 일일이 작성해주지 않아도, "더 높은 보상을 주는 방향"으로 스스로 유용한 문장을 만들어내도록 재학습(Fine-tuning)하게 됩니다.
</details>

    = Bradley-Terry 모델에 기반을 두고 있으며, 명칭은 주로 보상 모델 학습을 위한 Pairwise Cross-Entropy Loss

<details><summary>Pairwise Cross-Entropy Loss</summary>

**함수 수식**

$$J_{RM}(\phi) = -\mathbb{E}_{(x, y^w, y^l) \sim D} \left[ \log \sigma \left( RM_\phi(x, y^w) - RM_\phi(x, y^l) \right) \right]$$

**변수 정의**
* $\phi$: 보상 모델(Reward Model)의 파라미터(가중치)
* $x$: 입력 지시문 또는 프롬프트 (Prompt)
* $y^w$: 선호하는 응답 (Winning sample, 선호 응답)
* $y^l$: 비선호하는 응답 (Losing sample, 비선호 응답)
* $RM_\phi(x, y)$: 입력 $x$와 응답 $y$에 대해 보상 모델이 예측한 보상 점수 (Scalar)
* $\sigma(z)$: 시그모이드 함수 ($\frac{1}{1 + e^{-z}}$), 두 응답 간 점수 차이를 0과 1 사이의 확률값으로 변환
* $D$: 인간이 평가한 쌍대 비교(Pairwise comparison) 데이터셋

**핵심 설명**
* **목적**: 절대적 점수 대신 두 응답 간의 상대적 우열(Pairwise Comparison)을 기반으로 인간의 선호도를 학습하는 Bradley-Terry 모델 기반 손실 함수(Loss Function)
* **원리**: 선호 응답 $y^w$의 점수가 비선호 응답 $y^l$의 점수보다 높아지도록($RM_\phi(x, y^w) > RM_\phi(x, y^l)$) 차이를 최대화하여 손실(Loss)을 최소화함

**핵심 작동 방식 및 적용 예시**

* **상대적 비교 학습 (Pairwise Preference)**
* **원리**: 사람이 절대 점수를 매기는 대신 "A 응답이 B 응답보다 낫다"라는 상대적 우열을 판단하도록 하여 데이터의 일관성을 높입니다.
* **예시**: 지진 기사 프롬프트 $x$에 대해 인간이 $y_2 > y_1 > y_3$ 순으로 평가하면, $(y_2, y_1)$, $(y_1, y_3)$, $(y_2, y_3)$의 3가지 쌍(Pair) 데이터를 생성합니다.


* **승률 확률 변환 (Sigmoid Optimization)**
* **원리**: 선호 응답($y^w$)과 비선호 응답($y^l$)의 보상 점수 차이($RM(y^w) - RM(y^l)$)에 시그모이드 함수($\sigma$)를 적용해 "선호 응답이 이길 확률"로 변환합니다.
* **예시**: $(y_2, y_1)$ 쌍에서 $RM(x, y_2) - RM(x, y_1)$ 차이가 커질수록 $\sigma$ 값은 1(100% 승리)에 가까워집니다.


* **손실(Loss) 최소화**
* **원리**: 선호 응답의 점수가 비선호 응답보다 높을수록 시그모이드 값이 1에 가까워져 $-\log(1) = 0$에 수렴(Loss 최소화)하고, 반대로 순위가 뒤바뀌면 손실 값이 매우 커지도록 모델을 학습시킵니다.
* **예시 수식**:

$$Loss = -\left[ \log \sigma(RM(x, y_2) - RM(x, y_1)) + \log \sigma(RM(x, y_1) - RM(x, y_3)) + \log \sigma(RM(x, y_2) - RM(x, y_3)) \right]$$

<details><summary>DPO 정의 및 특징</summary>

DPO(Direct Preference Optimization)는 RLHF에서 보상 모델(Reward Model) 구축과 복잡한 강화학습(PPO) 단계를 생략하고, **언어모델을 직접 최적화하는 학습 방식**입니다.

**핵심 특징**

  * **복잡성 제거**: 보상 모델을 따로 학습하거나 PPO 같은 강화학습 알고리즘을 거치지 않아 학습 절차가 훨씬 간단하고 가볍습니다.
  * **수학적 재구수화**: RLHF의 손실 함수를 수학적으로 변형하여, 모델이 생성하는 응답의 확률 분포($p_\theta$) 자체로 보상 점수를 대체합니다.
  * **학습 안정성**: 강화학습 특유의 하이퍼파라미터 민감성이나 불안정한 수렴 문제가 없어 비교적 안정적으로 학습이 진행됩니다.

**작동 방식 및 수식 구조**
DPO는 인간이 선호하는 응답($y^w$)의 생성 확률은 높이고, 비선호하는 응답($y^l$)의 생성 확률은 낮추는 방식을 취합니다. (선호 응답 > 비선호 응답 최대화)
</details>

<details><summary>RLVR 정의 및 특징</summary>

**1. 정의**
  * **검증 가능한 보상 기반 강화학습**: 주관적인 인간의 선호도(Human Feedback) 대신, 수학 문제나 코딩처럼 정답 유무를 명확히 검증할 수 있는 객관적 규칙/검증기(Verifiable Reward)를 통해 보상을 부여하는 강화학습 방식입니다.

**2. 주요 특성**
  * **명확한 보상 함수**: 응답이 정답이면 $\gamma$, 오답이면 $0$과 같이 이진화(Binary)되거나 명확하게 규칙 기반으로 책정되는 스칼라 보상($r_i$)을 사용합니다.
  * **보상 모델(RM) 불필요**: 별도의 보상 모델을 사람이 매긴 데이터로 학습시킬 필요 없이, 코드 실행기(Compiler)나 정답 비교 프로그램만으로 자동 보상을 부여합니다.
  * **추론/논리 능력 강화**: 객관적 정답을 도출하는 과제(수학, 코딩, 논리적 추론)에 특화되어 있으며, 대표적 성공 사례로 **DeepSeek-R1**이 있습니다.

3. 원리: 정답이면 1, 아니면 0
</details>

<details><summary>Bi-encoder와 Cross-encoder 비교</summary>

| 구분 | Bi-encoder | Cross-encoder |
| --- | --- | --- |
| **처리 방식** | 두 문장($x_u, x_v$)을 각각 **독립적으로 인코딩** 후 코사인 유사도($\text{sim}_{\text{bi}}$) 계산 | 두 문장($x_u, x_v$)을 하나의 모델에 **동시에 입력**하여 유사도($\text{sim}_{\text{cr}}$) 계산 |
| **속도 및 효율** | **매우 빠름** (문장 임베딩을 미리 계산해 둘 수 있어 대규모 DB 검색에 적합) | **매우 느림** (모든 문장 쌍에 대해 매번 인코더 연산을 거쳐야 함) |
| **정확도** | 비교적 낮음 (두 문장 간 직접적인 어텐션 교류 없음) | **매우 높음** (문장 간 세밀한 상호작용 및 맥락을 교차 포착) |
| **주요 활용** | 1차 대량 문서 검색 (Candidate Generation / Retrieval) | 2차 상위 문서 재순위화 (Reranking) |

**요약**
  * **Bi-encoder**: 속도가 빨라 **대용량 검색**에 적합하지만 정확도가 떨어집니다.
  * **Cross-encoder**: 문장 간 맥락을 세밀하게 파악해 **정확도**가 높지만 속도가 느립니다.
  * 실제 시스템에서는 Bi-encoder로 후보를 빠르게 추린 뒤, Cross-encoder로 정밀하게 재정렬(Rerank)하는 조합을 주로 사용합니다.

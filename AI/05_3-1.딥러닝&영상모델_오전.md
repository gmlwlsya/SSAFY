## 1-2. CNN 모델 구조 - 중첩
#### 합성곱 레이어
![alt text](image_day5/1-2.35.png)
- 상수를 곱하는 것이 의미가 없게 됨 왜?

![alt text](image_day5/1-2.36.png)
- 그래서 비선형으로 만드는 ReLU 도입

#### 필터 시각화
![alt text](image_day5/1-2.37.png)
- 선형모델: **대표 템플릿**을 찾음
  - w * x의 형태 였음 
  - y = 3072(w) * 10(x)
  - y는 10개의 확률을 나타내며 각 클래스에 대응하는 값
  - w가 각각이 의미하는 것이 뭐냐? 클래스에서 가장 대표되는 템플릿이더라.  
    - 1번째는 plane 2번째는 car ...
  - 단점은 대표값으로만 한정이 되니 다양한 형태의 자동차 템플릿을 볼 수 없음 => 일반호 어려움 
    - 예시: 자동차 중에서도 빨간 자동차라면? 분류 어려움
<br>

- FCN: **다양한 템플릿** 제공
  - 선형모델 fcn을 한 번만 적용했을 때의 경우인데 만약 fcn을 여러 개를 이어서 그 사이에 비선형모델을 넣는다면? -> 다양한 템플렛 제공 가능 -> 성능 개선 가능
<br>

- CNN: **지역적 템플릿** 찾음
  - FCN과 어떻게 다를까? 계층별로 다른 템플릿 제공 가능
  - 지역적 패턴 탐색 -> 레이어 상승 시마다 점진적으로 다루는 패턴 탐색 범위가 넓어짐 -> 최종적으로 이미지 객체를 보게됨 
  - 예를 들어 우리가 다루는 모든 이미지 개체가 다양한 종류이 새라면?
    - 우리는 이 새들을 구분하는 기준이 부리의 모양, 색깔의 차이 등을 고려해야 함 -> cnn의 장점과 같음

#### 중첩과 수용영역
![alt text](image_day5/1-2.중첩과수용영역.png)
- 네트워크 디자인을 할 때도 수용영역을 넓게 하려는 노력을 함 -> 왜 넓게 하려고 하는지 ?
- 입력에 가까울 수록 지역적으로 작은 부분만 봄

![alt text](image_day5/1-2.39.png)
- 왜 레이어를 쌓을 수록 수용영역이 넓어질까요?
- 모든 레이어는 3*3임 
 -> 이 지역만 보면 수용영역이 3*3이 끝임
- 하지만, 입력 이후 conv layer 1의 3*3은 한 칸 마다 입력의 3*3의 값이 입력돼 있기 때문에 똑깥은 3*3을 보지만 conv layer1 의 3*3은 입력의 훨씬 큰 부분을 본 것과 같음
- 최종적으로 출력값은 모든 영역을 본 값이다.

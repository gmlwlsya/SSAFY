## 3. Python 인터프리터 사용 방법

### 3.1. 대화형 인터프리터 Shell 사용
`shell`이라는 프로그램으로 한 번에 한 명령어씩 입력해서 즉시 실행하는 방식입니다.

1. 터미널을 켜고 `python -i`를 입력하면 파이썬 인터프리터 환경이 실행됩니다.

```bash
$ python -i
Python 3.11.9 (tags/v3.11.9:de54cf5, Apr 2 2024, 10:12:12) [MSC v.1938 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.
>>> print('hello world')
hello world
>>> 
```

> 💡 **TIP**
> * `python -i` : 인터프리터 환경을 실행하는 명령어입니다.
> * `>>>` : Python shell의 입력 프롬프트입니다. 이 상태에서 파이썬 명령어를 직접 입력할 수 있습니다.

---

### 3.2. Script 파일 (.py) 실행
확장자가 `.py`인 파일에 작성된 Python 프로그램을 한 번에 실행하는 방식입니다.

1. `sample.py`라는 이름의 파이썬 파일을 생성하고 소스 코드를 작성합니다.

```python
# sample.py
print('hello')
```

2. Visual Studio Code 등 에디터에서 작성한 뒤, 터미널에서 실행합니다.

```bash
$ python sample.py
hello
```

## 5. 변수명 규칙

> 💡 **변수명이란?**  
> 우리가 외우기 힘든 '사물함 번호' 대신, 내용물을 쉽게 기억하기 위해 붙이는 **'사물함의 별명'**  
> 사람이 데이터를 쉽게 다루기 위해 만드는 **인간 친화적인 이름**

### 📌 변수 명명 규칙 (Naming Rules)
* **영문 알파벳, 언더스코어(`_`), 숫자**로 구성됩니다.
* **숫자로 시작할 수 없습니다.**
* **대소문자를 구분**합니다. (e.g., `Value`와 `value`는 전혀 다른 변수)
* 아래 **파이썬 내부 예약어(Keywords)**는 변수명으로 사용할 수 없습니다.

```python
['False', 'None', 'True', '__peg_parser__', 'and', 'as', 'assert',
 'async', 'await', 'break', 'class', 'continue', 'def', 'del',
 'elif', 'else', 'except', 'finally', 'for', 'from', 'global',
 'if', 'import', 'in', 'is', 'lambda', 'nonlocal', 'not',
 'or', 'pass', 'raise', 'return', 'try', 'while', 'with', 'yield']
```

## 6. 변수, 값 그리고 메모리

### 6.1. 메모리 주소 (Memory Address)
* 거리에 집 주소가 있듯이, 메모리의 모든 위치에는 그 위치를 고유하게 식별하는 **메모리 주소**가 존재합니다.
> 💡 **메모리 주소:** 각 사물함을 구별하기 위해 붙어있는 절대 겹치지 않는 고유한 '사물함 번호' (컴퓨터가 특정 데이터 값을 정확히 찾아가기 위해 사용하는 기계적인 숫자 주소)

---

### 6.2. 객체 (Object) 개념
파이썬에서는 **값 + 타입 + 주소 정보**를 하나로 묶은 것을 **객체(Object)**라고 부릅니다.
* **고유한 ID (메모리 주소):** 제품의 바코드 역할
* **타입 (Type):** 제품의 종류 (예: 정수`int`, 실수`float`, 문자열`str` 등)
* **값 (Value):** 제품의 실제 내용물

> 💡 **객체(Object):** 값, 타입, 그리고 관련된 행동까지 하나로 묶인 개념으로, **파이썬에서 다루는 모든 데이터의 실체**입니다.

---

## 7. 할당문 동작 순서 및 재할당

### 7.1. 할당문 동작 순서
```python
Variable = expression
```

1. **오른쪽 표현식 평가:** 가장 먼저 할당 연산자(`=`)의 오른쪽에 있는 표현식 전체를 계산하여 하나의 결과값(객체)을 만듭니다.
2. **왼쪽 변수명 확인:** 
   * 이름이 처음 사용되었다면 새로운 '이름표'를 준비합니다.
   * 이미 존재하는 이름이라면 기존 '이름표'를 그대로 사용합니다.
3. **변수명과 결과값 연결 (참조):** 
   * 왼쪽의 변수명이 오른쪽에서 만들어진 결과값을 가리키도록 연결합니다.
   * 만약 변수명이 이전에 다른 객체를 가리키고 있었다면, 그 연결은 끊어지고 새로운 객체와의 연결만 남습니다. (재할당)

---

### 7.2. 재할당 (Reassignment)
* 변수는 특정 값을 **기억**하거나 **가리키는** 이름입니다.
* **재할당**은 이 변수가 가리키는 대상을 새로운 값으로 변경하는 행위입니다.
* 재할당이 이루어지면, 변수는 이전 값을 완전히 잊고 **새로운 값만 기억**하게 됩니다.

```python
degrees = 'hello'
```

---

### 7.3. 재할당 예제 분석

```python
number = 10
double = 2 * number
print(double)  # 출력: 20

number = 5
print(double)  # 출력: ??
```

**🔍 정답: `20`**

* **원리 설명:**
  `number`에 `5`를 재할당하더라도, `double` 변수는 여전히 값 `20`을 참조하는 이름이라는 사실이 변하지 않습니다.
  단지 `number` 변수가 가리키는 '대상'이 `10`에서 `5`로 바뀐 것뿐이며, `double`이 자동으로 재계산되지는 않습니다.


## 8. 변수와 메모리 정리

| 용어 | 핵심 정의 | 비유 (주소록) |
| :--- | :--- | :--- |
| **객체 (Object)** | 데이터(값, 타입, 행동)의 실체 | '김철수'라는 실제 사람 |
| **메모리 주소** | 객체가 저장된 고유한 위치 | 김철수의 실제 집 주소 |
| **변수 (Variable)** | 객체를 가리키는 이름표 | 주소록에 저장된 '내 친구 철수'라는 이름 |

## 9. 타입(Type)과 데이터 타입(Data Types)

### 9.1. 타입 (Type) 이란?
> **변수나 값이 가질 수 있는 데이터의 종류**를 의미합니다.  
> 어떤 종류의 데이터인지, **어떻게 해석되고 처리되어야 하는지**를 정의합니다.

### 9.2. 데이터 타입 (Data Types) 이란?
> **값의 종류와 그 값으로 할 수 있는 '동작(연산)'을 결정하는 속성**  
> 어떤 데이터가 주어졌을 때 컴퓨터에게 **'이것은 무엇이고, 이걸로 무엇을 할 수 있는지'**를 알려주는 명세서입니다.

## 10. 데이터 타입 분류 5가지

* **Numeric Types**
  * `int` (정수), `float` (실수), `complex` (복소수)
* **Text Sequence Type**
  * `str` (문자열)
* **Sequence Types**
  * `list`, `tuple`, `range`
* **Non-sequence Types**
  * `set`, `dict`

## 11. 숫자형 데이터 (Numeric Types)

프로그래밍에서 값을 계산하고, 수량을 세고, 데이터를 분석하는 등 가장 기본이 되는 데이터 타입입니다.

파이썬의 숫자형은 크게 두 가지를 중심으로 살펴봅니다:
1. **정수형 (`int`):** 소수점이 없는 숫자 (양수, 0, 음수 포함)
2. **실수형 (`float`):** 소수점이 있는 더 정밀한 숫자

> 💡 **실수 (`float`):** 프로그래밍에서 소수점(`.`)이 있는 숫자를 나타내는 데이터 타입입니다.

## 12. 지수 표현법 (Exponential Notation)

* 아주 크거나 아주 작은 실수를 간결하게 표현하기 위해 사용하는 방식입니다.
* `'e'` 또는 `'E'`를 사용합니다.

> 💡 **지수:** 어떤 수를 그 자신과 여러 번 곱할 때, 그 곱하는 횟수를 나타내는 수 ('거듭제곱'에서 오른쪽 위에 작게 쓰이는 숫자)

```python
# 1,230,000,000 (1.23 * 10^9)
big_number = 1.23e9

# 0.00314 (3.14 * 10^-3)
small_number = 3.14e-3
```

## 13. 숫자형의 '행동' - 산술 연산자

* 숫자형 데이터의 핵심 '행동'은 바로 **계산**입니다.
* 데이터 타입은 **'값의 종류'**와 **'적용 가능한 행동'**의 묶음입니다.
* 파이썬은 다양한 계산을 위한 산술 연산자를 제공합니다.

### 📌 산술 연산자 종류 (Arithmetic Operators)

| 기호 | 설명 |
| :---: | :--- |
| `+` | 덧셈 |
| `-` | 뺄셈 |
| `*` | 곱셈 |
| `/` | 나눗셈 |
| `//` | 몫 나눗셈 |
| `%` | 나머지 |
| `**` | 거듭제곱 |
| `-` | 음수 부호 |


## 14. 연산자 우선순위 (Operator Precedence)

* 수학과 마찬가지로, 파이썬도 정해진 순서에 따라 연산을 수행합니다.

### 📌 연산자 우선순위 표

| 우선순위 | 연산자 | 연산 |
| :---: | :---: | :--- |
| **높음** | `**` | 지수 |
| | `-` | 음수 부호 |
| | `*`, `/`, `//`, `%` | 곱셈, 나눗셈, 정수 나눗셈, 나머지 |
| **낮음** | `+`, `-` | 덧셈, 뺄셈 |

### 📌 거듭제곱과 음수 부호 예제

```python
# -2 ** 4 -> -(2 ** 4) 와 동일하게 평가됨
-2 ** 4      # 결과: -16

-(2 ** 4)    # 결과: -16

(-2) ** 4    # 결과: 16
```

## 15. 시퀀스 타입 (Sequence Types)

### 15.1. 시퀀스 타입이란?
> **여러 개의 값들을 순서대로 나열하여 저장하는 자료형**

* **Sequence(시퀀스):** 여러 데이터가 정해진 순서대로 일렬로 늘어선 자료 구조
* **파이썬의 대표 시퀀스 타입:** `str`, `list`, `tuple`, `range`
* **인덱스 (Index):** 시퀀스 자료형에서 각 값의 위치를 식별하기 위해 부여된 고유한 번호

> 💡 **TIP**
> * 각 데이터는 기차 칸처럼 순서대로 연결되어 있습니다.
> * 모든 칸에는 0번부터 시작하는 고유한 번호(인덱스)가 붙어 있습니다.
> * 이 번호를 통해 원하는 칸의 데이터에 바로 접근할 수 있습니다.

### 15.2. 시퀀스 타입의 5가지 공통 특징
1. **순서(Order):** 값들이 순서대로 저장됨 (정렬 X)
2. **인덱싱(Indexing):** 각 값에 고유 번호(인덱스)를 가지고 있으며, 인덱스를 사용하여 특정 위치의 값을 선택하거나 수정할 수 있음
3. **슬라이싱(Slicing):** 인덱스 범위를 조절해 전체 데이터 중 원하는 부분만 값을 잘라내서 사용할 수 있음
4. **길이(Length):** `len()` 함수를 사용하여 저장된 값의 개수(길이)를 구할 수 있음
5. **반복(Iteration):** 반복문을 사용하여 각 값을 하나씩 순서대로 꺼내 사용할 수 있음

## 16. 문자열 (str)

### 16.1. 문자열이란?
> **문자들의 순서가 있는 변경 불가능한(Immutable) 시퀀스 자료형**  
> 글자들의 시퀀스, 텍스트 데이터를 다루는 방법입니다.

### 16.2. 문자열 만들기 1 - 따옴표 활용
* 따옴표 안에 다른 따옴표를 넣고 싶을 때는 **서로 다른 종류의 따옴표**를 사용합니다.

### 16.3. 문자열 만들기 2 - 특수 표현 & 이스케이프 시퀀스
* **이스케이프 시퀀스 (Escape Sequence):** 역슬래시(`\`)와 문자를 조합해 특별한 기능을 수행 (e.g. 줄바꿈, 탭)

```python
# 따옴표 앞에 \를 붙여 문자로 인식시킴
print('He\'s a boy.')

# \n 은 줄바꿈(엔터)을 의미함
print('첫째 줄\n둘째 줄')

# 여러 줄 문자열을 작성할 때는 따옴표 3개를 사용
multi_line_str = """이것은
여러 줄로 이루어진
문자열입니다."""

print(multi_line_str)
```

### 📌 이스케이프 시퀀스 예약 문자 정리

| 예약 문자 | 기능 |
| :---: | :--- |
| `\n` | 줄 바꿈 |
| `\t` | 탭 |
| `\\` | 백슬래시 |
| `\'` | 작은 따옴표 |
| `\"` | 큰 따옴표 |

## 5. 변수명 규칙

> 💡 **변수명이란?**
> 우리가 외우기 힘든 '사물함 번호' 대신, 내용물을 쉽게 기억하기 위해 붙이는 **'사물함의 별명'**
> 사람이 데이터를 쉽게 다루기 위해 만드는 **인간 친화적인 이름**

## 6. 변수, 값 그리고 메모리

### 6.1. 메모리 주소 (Memory Address)

* 거리에 집 주소가 있듯이, 메모리의 모든 위치에는 그 위치를 고유하게 식별하는 **메모리 주소**가 존재합니다.

> 💡 **메모리 주소:** 각 사물함을 구별하기 위해 붙어있는 절대 겹치지 않는 고유한 '사물함 번호' (컴퓨터가 특정 데이터 값을 정확히 찾아가기 위해 사용하는 기계적인 숫자 주소)

---

### 6.2. 객체 (Object) 개념

파이썬에서는 **값 + 타입 + 주소 정보**를 하나로 묶은 것을 객체(Object)라고 부릅니다.

* **고유한 ID (메모리 주소):** 제품의 바코드 역할
* **타입 (Type):** 제품의 종류 (예: 정수`int`, 실수`float`, 문자열`str` 등)
* **값 (Value):** 제품의 실제 내용물

> 💡 **객체(Object):** 값, 타입, 그리고 관련된 행동까지 하나로 묶인 개념으로, **파이썬에서 다루는 모든 데이터의 실체**입니다.

## 7. 할당문 동작 순서 및 재할당

### 7.1. 할당문 동작 순서

Variable = expression

1. **오른쪽 표현식 평가:** 가장 먼저 할당 연산자(`=`)의 오른쪽에 있는 표현식 전체를 계산하여 하나의 결과값(객체)을 만듭니다.
2. **왼쪽 변수명 확인:**
* 이름이 처음 사용되었다면 새로운 '이름표'를 준비합니다.
* 이미 존재하는 이름이라면 기존 '이름표'를 그대로 사용합니다.


3. **변수명과 결과값 연결 (참조):**
* 왼쪽의 변수명이 오른쪽에서 만들어진 결과값을 가리키도록 연결합니다.
* 만약 변수명이 이전에 다른 객체를 가리키고 있었다면, 그 연결은 끊어지고 새로운 객체와의 연결만 남습니다. (재할당)



---

### 7.2. 재할당 (Reassignment)

* 변수는 특정 값을 **기억**하거나 **가리키는** 이름입니다.
* **재할당**은 이 변수가 가리키는 대상을 새로운 값으로 변경하는 행위입니다.
* 재할당이 이루어지면, 변수는 이전 값을 완전히 잊고 **새로운 값만 기억**하게 됩니다.

degrees = 'hello'

---

### 7.3. 재할당 예제 분석

number = 10
double = 2 * number
print(double)  # 출력: 20

number = 5
print(double)  # 출력: 20

* **원리 설명:**
`number`에 `5`를 재할당하더라도, `double` 변수는 여전히 값 `20`을 참조하는 이름이라는 사실이 변하지 않습니다.
단지 `number` 변수가 가리키는 '대상'이 `10`에서 `5`로 바뀐 것뿐이며, `double`이 자동으로 재계산되지는 않습니다.

## 9. 타입(Type)과 데이터 타입(Data Types)

### 9.1. 타입 (Type) 이란?

> **변수나 값이 가질 수 있는 데이터의 종류**를 의미합니다.
> 어떤 종류의 데이터인지, **어떻게 해석되고 처리되어야 하는지**를 정의합니다.

### 9.2. 데이터 타입 (Data Types) 이란?

> **값의 종류와 그 값으로 할 수 있는 '동작(연산)'을 결정하는 속성**
> 어떤 데이터가 주어졌을 때 컴퓨터에게 **'이것은 무엇이고, 이걸로 무엇을 할 수 있는지'**를 알려주는 명세서입니다.

## 11. 숫자형 데이터 (Numeric Types)

프로그래밍에서 값을 계산하고, 수량을 세고, 데이터를 분석하는 등 가장 기본이 되는 데이터 타입입니다.

파이썬의 숫자형은 크게 두 가지를 중심으로 살펴봅니다:

1. **정수형 (`int`):** 소수점이 없는 숫자 (양수, 0, 음수 포함)
2. **실수형 (`float`):** 소수점이 있는 더 정밀한 숫자

> 💡 **실수 (`float`):** 프로그래밍에서 소수점(`.`)이 있는 숫자를 나타내는 데이터 타입입니다.

## 12. 지수 표현법 (Exponential Notation)

* 아주 크거나 아주 작은 실수를 간결하게 표현하기 위해 사용하는 방식입니다.
* `'e'` 또는 `'E'`를 사용합니다.

> 💡 **지수:** 어떤 수를 그 자신과 여러 번 곱할 때, 그 곱하는 횟수를 나타내는 수 ('거듭제곱'에서 오른쪽 위에 작게 쓰이는 숫자)

# 1,230,000,000 (1.23 * 10^9)
big_number = 1.23e9

# 0.00314 (3.14 * 10^-3)
small_number = 3.14e-3

## 13. 숫자형의 '행동' - 산술 연산자

* 숫자형 데이터의 핵심 '행동'은 바로 **계산**입니다.
* 데이터 타입은 '값의 종류'와 '적용 가능한 행동'의 묶음입니다.
* 파이썬은 다양한 계산을 위한 산술 연산자를 제공합니다.

### 📌 산술 연산자 종류 (Arithmetic Operators)

| 기호 | 설명 |
| --- | --- |
| `+` | 덧셈 |
| `-` | 뺄셈 |
| `*` | 곱셈 |
| `/` | 나눗셈 |
| `//` | 몫 나눗셈 |
| `%` | 나머지 |
| `**` | 거듭제곱 |
| `-` | 음수 부호 |

## 14. 연산자 우선순위 (Operator Precedence)

* 수학과 마찬가지로, 파이썬도 정해진 순서에 따라 연산을 수행합니다.

### 📌 연산자 우선순위 표

| 우선순위 | 연산자 | 연산 |
| --- | --- | --- |
| **높음** | `**` | 지수 |
|  | `-` | 음수 부호 |
|  | `*`, `/`, `//`, `%` | 곱셈, 나눗셈, 정수 나눗셈, 나머지 |
| **낮음** | `+`, `-` | 덧셈, 뺄셈 |

### 📌 거듭제곱과 음수 부호 예제

# -2 ** 4 -> -(2 ** 4) 와 동일하게 평가됨
-2 ** 4      # 결과: -16

-(2 ** 4)    # 결과: -16

(-2) ** 4    # 결과: 16

## 15. 시퀀스 타입 (Sequence Types)

### 15.1. 시퀀스 타입이란?

> **여러 개의 값들을 순서대로 나열하여 저장하는 자료형**

* **Sequence(시퀀스):** 여러 데이터가 정해진 순서대로 일렬로 늘어선 자료 구조
* **파이썬의 대표 시퀀스 타입:** `str`, `list`, `tuple`, `range`
* **인덱스 (Index):** 시퀀스 자료형에서 각 값의 위치를 식별하기 위해 부여된 고유한 번호

> 💡 **TIP**
> * 각 데이터는 기차 칸처럼 순서대로 연결되어 있습니다.
> * 모든 칸에는 0번부터 시작하는 고유한 번호(인덱스)가 붙어 있습니다.
> * 이 번호를 통해 원하는 칸의 데이터에 바로 접근할 수 있습니다.
> 
> 

### 15.2. 시퀀스 타입의 5가지 공통 특징

1. **순서(Order):** 값들이 순서대로 저장됨 (정렬 X)
2. **인덱싱(Indexing):** 각 값에 고유 번호(인덱스)를 가지고 있으며, 인덱스를 사용하여 특정 위치의 값을 선택하거나 수정할 수 있음
3. **슬라이싱(Slicing):** 인덱스 범위를 조절해 전체 데이터 중 원하는 부분만 값을 잘라내서 사용할 수 있음
4. **길이(Length):** `len()` 함수를 사용하여 저장된 값의 개수(길이)를 구할 수 있음
5. **반복(Iteration):** 반복문을 사용하여 각 값을 하나씩 순서대로 꺼내 사용할 수 있음

## 16. 문자열 (str)

### 16.2. 문자열 만들기 1 - 따옴표 활용

* 따옴표 안에 다른 따옴표를 넣고 싶을 때는 **서로 다른 종류의 따옴표**를 사용합니다.

* **이스케이프 시퀀스 (Escape Sequence):** 역슬래시(`\`)와 문자를 조합해 특별한 기능을 수행 (e.g. 줄바꿈, 탭)

## 17. 코드에서 진법 표현하기

* 파이썬은 코드 내에서 다양한 진법의 숫자를 직접 표현할 수 있도록 특별한 접두사(prefix)를 제공합니다.

### 📌 진법 표현 정리

| 진법 | 접두사 | 사용하는 숫자/문자 |
| --- | --- | --- |
| **2진수 (binary)** | `0b` | 0 과 1 |
| **8진수 (octal)** | `0o` | 0 부터 7 까지 |
| **16진수 (hexadecimal)** | `0x` | 0 부터 9, a 부터 f 까지 |

# 2진수 10은 10진수로 2입니다. (1 * 2^1 + 0 * 2^0)
print(0b10)    # 출력: 2

# 8진수 30은 10진수로 24입니다. (3 * 8^1 + 0 * 8^0)
print(0o30)    # 출력: 24

# 16진수 10은 10진수로 16입니다. (1 * 16^1 + 0 * 16^0)
print(0x10)    # 출력: 16

> 💡 **TIP**
> 어떤 진법으로 코드를 작성하든, 파이썬은 내부적으로 모두 같은 숫자 값으로 인식하며, `print()` 함수는 그 값을 우리에게 익숙한 **10진수로 변환하여 출력**합니다.

## 18. 부동소수점 (반올림) 오차

### 18.1. 실수의 이상한 계산 결과

result = 0.1 + 0.2

print(result == 0.3)  # 출력: False
print(result)         # 출력: 0.30000000000000004

### 18.2. 부동소수점 오차 발생 원인

1. **컴퓨터는 2진수를 사용:** 컴퓨터는 모든 숫자를 0과 1로 이루어진 2진수로 변환하여 저장합니다.
2. **무한 소수의 발생과 근사값 저장:** 우리가 쓰는 10진수 소수 중 일부(예: `0.1`)는 2진수로 바꾸면 무한히 반복되는 무한 소수가 됩니다.
* `0.1 (10진수)` $\rightarrow$ `0.0001100110011... (2진수)`


3. **메모리의 한계:** 메모리는 유한하기 때문에, 컴퓨터는 이 무한 소수를 어쩔 수 없이 가장 가까운 **근사값**으로 잘라서 저장합니다.

> 🚨 이 근사치 때문에 미세한 오차가 발생하고, 연산 과정에서 의도치 않은 문제가 발생할 수 있습니다.

### 18.3. 해결책: 정확한 계산이 필요할 때 (`decimal` 모듈)

* 대표적으로 `decimal` 모듈을 사용해 부동소수점 연산의 정확성을 보장할 수 있습니다.
* `decimal`은 실수를 2진수로 변환하지 않고, **10진수 자체로 정확하게 연산**할 수 있게 해줍니다.

# [해결 전]
a = 3.2 - 3.1
b = 1.2 - 1.1

print(a)       # 출력: 0.10000000000000009
print(b)       # 출력: 0.09999999999999987
print(a == b)  # 출력: False

# [해결 후]
from decimal import Decimal

a = Decimal('3.2') - Decimal('3.1')
b = Decimal('1.2') - Decimal('1.1')

print(a)       # 출력: 0.1
print(b)       # 출력: 0.1
print(a == b)  # 출력: True

## 19. 인덱스 (Index) 와 인덱싱

### 19.1. 인덱스란?

> **시퀀스 자료형에서 각 값의 위치를 식별하기 위해 부여된 고유한 번호**

### 📌 인덱스는 왜 0부터 시작할까요?

프로그래밍에서 인덱스가 1이 아닌 0부터 시작하는 것은 **'거리'의 개념**으로 이해하면 쉽습니다.

* 인덱스는 "시작점으로부터 얼마나 떨어져 있는가"를 의미합니다.
* 첫 번째 값은 시작점 바로 그 자체이므로, 떨어진 거리가 **0**입니다.
* 두 번째 값은 시작점에서 **1만큼** 떨어져 있습니다.
* 따라서 `index 0`은 '첫 번째 항목'을 의미하며, 이는 대부분의 프로그래밍 언어에서 통용되는 매우 중요한 규칙입니다.

## 20. 슬라이싱 (Slicing)

### 20.1. 슬라이싱 사용 방법

> 대괄호 `[]` 안에 시작 위치, 끝 위치, 간격(step)을 콜론(`:`)으로 구분하여 지정합니다.

my_sequence[start:stop:step]

1. `start`: 슬라이싱을 시작할 인덱스 (**포함됨**)
2. `stop`: 슬라이싱을 끝낼 인덱스 (**포함되지 않음**)
3. `step`: 몇 개씩 건너뛰며 값을 가져올지에 대한 간격

## 22. 문자열 수정 및 재할당 (Immutable)

### 22.1. 문자열을 바꾸려면?

> 문자열은 변경 불가능(Immutable)하므로, 기존 문자열의 일부와 새로운 값을 조합하여 **새로운 문자열을 만들어야 합니다.**

my_str = 'Hello'

# 기존 문자열의 일부와 새로운 문자를 조합
new_str = my_str[0] + 'a' + my_str[2:]

print(new_str)  # 출력: Hallo

> 💡 **TIP: `my_str = 'Hallo'`로 작성하면 변경된 것 아닌가요?**
> 아닙니다. 그것은 `my_str` 내부의 값을 변경한 것이 아니라 새로운 값으로 **"재할당"**한 것입니다.

## 24. 표현식(Expression) vs 문장(Statement)

> 💡 **구분하는 핵심 질문**
> *"이 코드를 실행하면, 그래서 '하나의 값'이 남나요?"*

* **표현식 (Expression)**
* 어떻게든 계산되거나 평가되어 **하나의 '값'으로 귀결되는 모든 코드** (변수에 담을 수 있음)
* `10 + 20` $\rightarrow$ 값 `30`이 남음
* `len("hello")` $\rightarrow$ 값 `5`가 남음


* **문장 (Statement)**
* 컴퓨터에게 특정 동작을 '지시'하고 끝나는 코드 (값 자체가 남지 않음)
* `name = "홍길동"` $\rightarrow$ 값을 변수에 할당하라는 '지시'

## 25. 파이썬 스타일 가이드 (Style Guide & PEP 8)

* **Style Guide란?**
* 여러 사람이 함께 작업하거나 미래의 내가 코드를 쉽게 알아볼 수 있도록 코드의 **일관성과 가독성을 향상시키기 위한 규칙과 권장 사항들의 모음**


* **PEP 8 (Python Enhancement Proposal 8)**
* 파이썬 코드를 일관성 있고 읽기 쉽게 작성하기 위한 **공식 스타일 가이드**



### 📌 파이썬 대표 Style Guide 규칙

1. **직관적인 변수명:** 변수명은 무엇을 위한 변수인지 의미가 명확한 이름을 사용
2. **들여쓰기:** 공백(spaces) **4칸**을 사용하여 코드 블록을 들여쓰기
3. **줄 길이 제한:** 한 줄의 길이는 **79자**로 제한하며, 길어질 경우 줄 바꿈 사용
4. **네이밍 규칙:** 문자(소문자)와 밑줄(`_`)을 사용하여 함수, 변수, 속성 이름을 작성 (**snake_case**)
5. **빈 줄 추가:** 함수 정의나 클래스 정의 등 블록 사이에는 빈 줄을 추가

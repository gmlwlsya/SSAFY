
# 객체 지향 프로그래밍 (OOP)

## 1. 절차 지향 프로그래밍 (Procedural Programming)

### 개념

* **함수와 로직 중심**으로 코드를 작성하며, 데이터를 **순차적으로 처리**하는 방식입니다.

### 특징

* **흐름 중심:** 입력을 받아 처리하고 결과를 내는 과정이 위에서 아래로 순차적으로 흐릅니다.
* **데이터와 절차의 분리:** 변수(데이터)와 함수(절차)를 별개로 다룹니다.
* **비유:** 요리 레시피를 순서대로 하나씩 따라가는 것과 유사합니다.

### 코드 예시

```python
# 변수(데이터)
name = 'Alice'
age = 25

# 함수(절차)
def introduce(name, age):
    print(f'안녕하세요, {name}입니다. 나이는 {age}살입니다.')

# 순차적 실행 및 함수 호출
introduce(name, age)

```

---

## 2. 절차 지향 프로그래밍의 한계

1. **복잡성 증가:** 프로그램 규모가 커질수록 데이터와 함수의 관리가 어려워지며, 전역 변수 증가로 인한 관리의 한계가 발생합니다.
2. **유지보수 문제:** 코드를 수정할 때 어디까지 영향을 미치는지 범위 파악이 어렵습니다.

## 3. 객체 지향 프로그래밍 (Object-Oriented Programming)

### 개념

* 데이터(변수)와 그 데이터를 처리하는 함수(메서드)를 하나의 단위인 객체(Object)로 묶어서 조직적으로 관리하는 패러다임입니다.
* **클래스(Class):** 객체를 만들기 위한 **설계도**
* **인스턴스(Instance):** 클래스를 기반으로 만들어진 **실제 물건(객체)**

### 특징 및 비유

* **데이터와 메서드의 결합:** 주방 도구, 재료, 행동을 따로 보지 않고 '볶음밥 기계'라는 하나의 객체로 만들어, 기계가 알아서 재료와 행동을 관리하게 하는 방식입니다.

### 코드 예시

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f'안녕하세요, {self.name}입니다. 나이는 {self.age}살입니다.')

# 객체 생성 및 자기 자신 정보 출력
alice = Person('Alice', 25)
alice.introduce()

```

## 4. 절차 지향 vs 객체 지향 비교

| 구분 | 절차 지향 (Procedural) | 객체 지향 (OOP) |
| --- | --- | --- |
| **중심 요소** | 데이터와 함수(절차)가 **분리**됨 | 데이터와 함수(메서드)를 **하나의 객체로 묶음** |
| **핵심 포인트** | **함수 호출의 흐름**이 중요 | 객체 간의 **상호작용과 메시지 전달**이 중요 |
| **데이터의 성격** | 함수로 전달되는 **수동적 존재** | 스스로 기능을 수행하는 **능동적 존재** |

---

## 5. 객체 지향 패러다임의 핵심과 주의사항

### "데이터가 살아나다"

* 객체 지향에서는 데이터가 단순히 함수에 전달되는 수동적 역할에서 벗어나, **스스로 기능을 수행하는 능동적 존재**가 됩니다.
* 실제 세계의 모델링 방식과 유사하여 **코드의 구조화 및 재사용성**을 크게 높여줍니다.

### ⚠️ 주의사항: 대조되는 개념이 아닙니다

* 절차 지향과 객체 지향은 **반대되거나 배타적인 개념이 아닙니다.**
* 객체 지향은 기존 절차 지향을 기반으로 두되, 이를 보완하기 위해 '객체'라는 개념을 도입한 것입니다.
* 상속, 코드 재사용성, 유지보수성 등의 이점을 제공하는 발전된 패러다임입니다.

## 6. 객체(Object)의 상세 정의 및 특징

### 개념

* **객체(Object):** 실제 존재하는 사물을 추상화한 것으로, 속성(Attribute)과 동작(Method)을 가집니다.

### 주요 특징

* **속성 (Attribute):** 객체의 상태나 데이터를 의미합니다 (변수로 표현).
* **메서드 (Method):** 객체의 행동이나 기능을 의미합니다 (함수로 표현).
* **고유성:** 각 객체는 서로 구분되는 고유한 특성을 가집니다.

### 객체 예시

* **강아지:**
* **속성:** 이름, 종, 나이
* **동작:** 짓기, 뛰기


* **가수:**
* **속성(변수):** 직업(가수), 생년월일(1993년 5월 16일), 국적(대한민국)
* **동작(메서드):** `랩()`, `댄스()`, `바이브레이션()`

## 7. 클래스(Class)의 정의 및 선언

### 개념

* 관련 데이터(속성)와 기능(메서드)을 하나의 '묶음'으로 정의하는 설계도(Blueprint)이자 틀입니다.
* 클래스로부터 여러 개의 객체를 만들어낼 수 있으며, 사용자 정의 객체를 만드는 수단이 됩니다.

### 자동차 설계도 비유

1. **클래스(Class):** 자동차 설계도 (예: 特定 모델 '소나X'를 만들기 위한 완벽한 설계도)
2. **속성(Attribute):** 자동차의 데이터 (색상, 최고 속도, 좌석 수, 배기량 등)
3. **메서드(Method):** 자동차의 기능 (`가속하기()`, `정지하기()`, `방향 바꾸기()` 등)
4. **인스턴스(Instance):** 설계도를 바탕으로 공장에서 실제 생산된 '각각의 자동차'

### 파이썬 문법 규칙

* `class` 키워드를 사용합니다.
* 클래스 이름은 **파스칼 케이스(PascalCase)** 방식을 사용합니다.
* `__init__` 메서드는 생성자 메서드(Constructor)로 불리며, 새로운 객체를 만들 때 필요한 초기값을 설정합니다.

```python
class Person:
    # 생성자 메서드: 인스턴스 속성 초기화
    def __init__(self, name, age):
        self.name = name
        self.age = age

    # 인스턴스 메서드
    def introduce(self):
        print(f'안녕하세요. 저는 {self.name}, 나이는 {self.age}살입니다.')

```

## 8. 인스턴스(Instance)의 정의 및 생성

### 개념

* 클래스라는 설계도로부터 실제로 만들어낸 '개별 물건(객체)'입니다.

### 생성 예시

```python
# Person 클래스(설계도)로부터 인스턴스 p1, p2 생성
p1 = Person('Alice', 25)
p1.introduce()  # 출력: 안녕하세요. 저는 Alice, 나이는 25살입니다.

p2 = Person('Bella', 30)
p2.introduce()  # 출력: 안녕하세요. 저는 Bella, 나이는 30살입니다.

```

## 9. 클래스와 인스턴스의 관계

### 새로운 타입(Type)으로서의 클래스

* 공통된 특성과 기능을 가진 틀(클래스)을 만드는 것은 곧 **새로운 데이터 타입을 만드는 행위**입니다.
* 단순히 *"아이유는 인스턴스다"*라고 하면 어떤 타입인지 알 수 없으므로 모호하지만, *"아이유는 Singer 클래스의 인스턴스다"*라고 표현하면 명확해집니다.

```python
class Singer:
    def sing(self):
        return 'lalala'

iu = Singer()
print(iu.sing())      # lalala
print(type(iu))       # <class '__main__.Singer'> -> Python이 iu의 타입을 인식함

```

### 💡 파이썬 기본 데이터 타입의 비밀

* 파이썬에서 우리가 기본적으로 사용해 온 모든 데이터 타입(`str`, `int`, `list` 등)은 **사실 모두 클래스**였습니다.

```python
name = 'Alice'
print(type(name))  # <class 'str'> -> 변수 name은 str 클래스의 인스턴스임

```

## 10. 클래스 구조: 인스턴스 변수 vs 클래스 변수

### (1) 생성자 메서드 (`__init__`)

* 인스턴스 생성 시 **자동으로 호출**되는 특별한 메서드입니다.
* 인스턴스 변수의 **초기화**를 담당합니다.

### (2) 인스턴스 변수 (Instance Variable)

* **개념:** 각 인스턴스별로 독립적인 값을 유지하는 고유한 속성입니다.
* **정의 방식:** `self.변수명` 형태로 정의합니다.

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius  # 인스턴스 변수

c1 = Circle(1)
c2 = Circle(2)
print(c1.radius)  # 1
print(c2.radius)  # 2

```

### (3) 클래스 변수 (Class Variable)

* **개념:** 해당 클래스로부터 생성된 **모든 인스턴스가 공유**하는 속성입니다.
* **정의 방식:** 클래스 내부, 메서드 외부에서 직접 정의합니다.

```python
class Circle:
    pi = 3.14  # 클래스 변수

    def __init__(self, radius):
        self.radius = radius

c1 = Circle(5)
c2 = Circle(10)
print(c1.pi)  # 3.14
print(c2.pi)  # 3.14

```

### ⚠️ 변수 탐색 우선순위 (변수명 중복 시)

* 클래스 변수와 동일한 이름으로 인스턴스 변수를 생성할 경우, **인스턴스 변수를 먼저 참조**합니다.
* 명확하게 클래스 변수에 접근하려면 `클래스명.클래스변수` 형태를 사용하는 것이 좋습니다.

```python
c1 = Circle(5)
c1.pi = 100  # c1만의 인스턴스 변수 pi 생성

print(c1.pi)        # 100  (인스턴스 변수 우선 참조)
print(Circle.pi)    # 3.14 (클래스 변수 직접 참조)
print(c2.pi)        # 3.14 (c2는 인스턴스 변수 pi가 없으므로 클래스 변수 참조)

```

## 11. 메서드(Method)의 종류 및 인스턴스 메서드

### 개념

* 클래스 내부에 정의된 함수로, 해당 객체가 **어떻게 동작할지**를 코드(행동/기능)로 표현한 것입니다.
* **종류:**
1. **인스턴스 메서드 (Instance Method)**
2. 클래스 메서드 (Class Method)
3. 스태틱 메서드 (Static Method)



---

## 12. 인스턴스 메서드 (Instance Method)

### 개념 및 구조

* 인스턴스의 **상태를 조작하거나 동작을 수행**하는 메서드입니다.
* 클래스 내부에 정의되는 메서드의 기본 형태로, 반드시 첫 번째 인자로 인스턴스 자신(`self`)을 받습니다.

```python
class MyClass:
    def instance_method(self, arg1, ...):
        pass

```

> 💡 **참고:** `self`는 매개변수 이름일 뿐이라 다른 이름으로 바꿀 수 있지만, 파이썬 컨벤션상 **`self` 사용을 강력히 권장**합니다.

---

## 13. `self`의 동작 원리와 객체 지향적 표현

### 축약형 호출 vs 축약하지 않은 호출

문자열 `'hello'`를 대문자로 변경할 때 다음 두 방식은 내부적으로 동일하게 작동합니다.

* `'hello'.upper()` : 객체 지향 방식의 **단축형 호출** (객체가 스스로 메서드 호출)
* `str.upper('hello')` : `str` 클래스가 `upper` 메서드를 호출하고, 첫 번째 인자로 `'hello'` 인스턴스를 전달

### `self`가 첫 번째 인자인 이유

* 파이썬 내부적으로는 `str.upper('hello')`처럼 **클래스가 메서드를 실행할 때 해당 인스턴스를 첫 번째 매개변수(`self`)로 자동 전달**하기 때문입니다.
* 이를 통해 데이터가 단순히 함수의 인자로 전달되는 것이 아니라, **객체 스스로가 행동하는 주체**가 됩니다.

## 14. 인스턴스 메서드 활용 예시

```python
class Counter:
    # 생성자: 초기 상태 설정 (self == 앞으로 만들어질 인스턴스 자신)
    def __init__(self):
        self.count = 0  # 인스턴스 변수: 객체마다 따로 보관

    # 인스턴스 메서드: 자신의 count를 1 증가시킴 (self는 자동 전달)
    def increment(self):
        self.count += 1

c = Counter()     # 인스턴스 생성 -> __init__ 자동 실행
c.increment()     # 인스턴스 메서드 호출
print(c.count)    # 출력: 1

```

## 15. 생성자 메서드 (Constructor Method)

### 개념 및 역할

* **개념:** 인스턴스 객체가 생성될 때 **자동으로 호출**되는 특별한 메서드입니다.
* **역할:** 인스턴스 변수들의 **초기 값을 설정**합니다.

```python
class Person:
    def __init__(self, name):
        # 왼쪽 self.name : 인스턴스 변수 name
        # 오른쪽 name     : 생성자 메서드의 매개변수 name
        self.name = name
        print('인스턴스가 생성되었습니다.')

    def greeting(self):
        print(f'안녕하세요 {self.name}입니다.')

# 인스턴스 생성 시 __init__ 자동 실행
person1 = Person('지민')      # 출력: 인스턴스가 생성되었습니다.
person1.greeting()           # 출력: 안녕하세요 지민입니다.

```

## 16. 클래스 메서드 (Class Method)

### 개념 및 정의

* **개념:** 클래스 변수를 조작하거나 **클래스 레벨의 동작**을 수행하는 메서드입니다.
* **특징:**
* `@classmethod` 데코레이터를 사용하여 정의합니다.
* 호출 시 첫 번째 인자로 해당 메서드를 호출하는 클래스 자신(`cls`)이 전달됩니다.
* 클래스를 인자로 받아 클래스 속성을 변경하거나 읽는 데 사용됩니다.



> 💡 **참고:** `cls`는 매개변수 이름일 뿐이라 변경 가능하지만, 파이썬 컨벤션상 **`cls` 사용을 강력히 권장**합니다.

### 활용 예시

```python
class Person:
    population = 0  # 클래스 변수

    def __init__(self, name):
        self.name = name
        Person.increase_population()  # 생성 시 클래스 메서드 호출

    @classmethod
    def increase_population(cls):
        cls.population += 1  # 클래스 변수 조작

person1 = Person('Alice')
person2 = Person('Bella')

print(Person.population)  # 출력: 2

```

## 17. 스태틱(정적) 메서드 (Static Method)

### 개념 및 정의

* **개념:** 클래스나 인스턴스와 상관없이 **독립적으로 동작**하는 메서드입니다.
* **특징:**
* `@staticmethod` 데코레이터를 사용하여 정의합니다.
* 호출 시 자동으로 전달받는 인자가 없습니다 (`self`, `cls`를 받지 않음).
* 인스턴스나 클래스 속성에 직접 접근하지 않는, 일종의 **'도우미 함수(Helper Function)'** 역할을 합니다.



### 활용 예시

```python
class MathUtils:
    @staticmethod
    def add(a, b):
        return a + b

print(MathUtils.add(3, 5))  # 출력: 8

```

## 18. 종합 예제: 은행 계좌(`BankAccount`) 클래스

클래스 구조와 3가지 메서드(인스턴스 / 클래스 / 스태틱) 유형을 한눈에 비교할 수 있는 예제입니다.

### 클래스 구조 정의

```python
class BankAccount:
    # 1. 클래스 변수: 모든 인스턴스가 공유하는 이자율
    interest_rate = 0.02

    # 2. 생성자 메서드: 초기 계좌 정보 설정
    def __init__(self, owner, balance=0):
        self.owner = owner      # 인스턴스 변수: 계좌 소유자
        self.balance = balance  # 인스턴스 변수: 초기 잔액

    # 3. 인스턴스 메서드: 입금
    def deposit(self, amount):
        self.balance += amount

    # 4. 인스턴스 메서드: 출금 (조건문 검시)
    def withdraw(self, amount):
        if self.balance >= amount:
            self.balance -= amount
        else:
            print('잔액 부족!')

    # 5. 클래스 메서드: 이자율 변경 (전체 인스턴스에 영향)
    @classmethod
    def set_interest_rate(cls, rate):
        cls.interest_rate = rate

    # 6. 스태틱 메서드: 금액 유효성 검증 (독립 로직)
    @staticmethod
    def is_positive(amount):
        return amount > 0

```

### 클래스 활용 및 실행 결과

```python
# 계좌 개설 (인스턴스 생성)
alice_acc = BankAccount('Alice', 1000)

# 입금 및 출금 (인스턴스 메서드 호출)
alice_acc.deposit(500)
alice_acc.withdraw(200)

# 잔액 확인 (인스턴스 변수 참조)
print(alice_acc.balance)  # 1300

# 이자율 변경 (클래스 메서드 호출)
BankAccount.set_interest_rate(0.03)
print(BankAccount.interest_rate)  # 0.03

# 잔액이 양수인지 확인 (스태틱 메서드 독립 호출)
print(BankAccount.is_positive(alice_acc.balance))  # True

```

## 💡 메서드 종류 요약

| 구분 | 데코레이터 | 첫 번째 매개변수 | 주요 역할 |
| --- | --- | --- | --- |
| **인스턴스 메서드** | 없음 | `self` | 인스턴스 개별 상태 조작 및 동작 |
| **클래스 메서드** | `@classmethod` | `cls` | 클래스 변수 조작 및 클래스 레벨 동작 |
| **스태틱 메서드** | `@staticmethod` | 없음 | 객체 상태와 무관한 독립적 도우미 기능 |

## 19. 메서드 정리 및 선택 기준

### (1) 메서드 핵심 요약

* **인스턴스 메서드:** 인스턴스의 상태를 변경하거나 특정 동작을 수행
* **클래스 메서드:** 인스턴스 상태에 의존하지 않고, 클래스 변수를 조작하거나 클래스 레벨 동작을 수행
* **스태틱 메서드:** 클래스 및 인스턴스와 관련이 없는 독립적인/일반적인 기능을 수행

### (2) 주체별 사용 기준 (Should vs Can)

기술적으로 클래스가 모든 메서드를 호출할 수는 있지만(`Can`), 논리적인 사용 의도(`Should`)에 맞게 구분하여 사용해야 합니다.

* **클래스가 사용해야 할 것:** 클래스 메서드, 스태틱 메서드
* **인스턴스가 사용해야 할 것:** 인스턴스 메서드

> 💡 **메서드 선택 기준 (TIP)**
> * **개별 객체의 상태**를 다룰 때 $\rightarrow$ **인스턴스 메서드**
> * **공통 설정값**을 바꾸거나 **유틸리티성 처리**를 할 때 $\rightarrow$ **클래스/스태틱 메서드**
> * 핵심 질문: **"무엇을 바꾸는가?"**

## 20. 클래스와 인스턴스 간의 이름 공간 (Namespace)

### (1) 이름 공간 탐색 순서

1. **독립적 메모리 공간:** 클래스를 정의하면 **클래스 이름 공간**이, 인스턴스를 만들면 **독립적인 인스턴스 이름 공간**이 각각 생성됩니다.
2. **속성 탐색 순서:** `인스턴스 → 클래스` 순으로 탐색합니다.
3. **우선순위:** 동일한 이름의 속성이 중복되어 존재할 경우, **인스턴스 속성이 우선**합니다.

```python
class Person:
    name = 'unknown'  # 클래스 변수

    def talk(self):
        print(self.name)

p1 = Person()
p1.talk()  # 'unknown' (인스턴스 변수가 없어 클래스 변수 참조)

p2 = Person()
p2.name = 'Kim'  # p2 전용 인스턴스 변수 생성
p2.talk()  # 'Kim' (인스턴스 변수 우선 참조)

print(Person.name)  # 'unknown' (클래스 변수 값은 변하지 않음)

```

### (2) 독립적 이름 공간의 이점

* 객체 간 데이터/상태 직접 접근을 차단하여 **독립적 동작을 보장**합니다.
* 객체 간 충돌이나 원치 않는 영향을 방지하여 **가독성, 유지보수성, 재사용성**을 높여줍니다.

## 21. 매직 메서드 (Magic Method)

### 개념 및 특징

* 이름 앞뒤로 더블 언더스코어(`__`)가 붙는 특수한 인스턴스 메서드입니다. (스페셜 메서드라고도 부름)
* 특정 상황(예: 객체 생성, 출력, 연산 등)에서 **자동으로 호출**됩니다.

### 대표 예시: `__str__(self)`

* `print(객체)`를 호출할 때 자동으로 실행되어, 객체의 상태를 **사람이 읽기 쉬운 문자열 표현**으로 반환합니다.

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    def __str__(self):
        return f'원의 반지름: {self.radius}'

c1 = Circle(10)
print(c1)  # 출력: 원의 반지름: 10

```

* 주요 매직 메서드 목록:
* 생성자: `__init__`
* 문자열 표현: `__str__`
* 길이 표현: `__len__`
* 비교 연산: `__eq__` ($==$), `__ne__` ($\neq$), `__lt__` ($<$), `__le__` ($\le$), `__gt__` ($>$), `__ge__` ($\ge$)

## 22. 데코레이터 (Decorator)

### 개념 및 구조

* 다른 함수의 코드를 직접 수정하지 않고, 기능을 추가하거나 확장(wraps)하기 위해 사용되는 함수입니다.
* 메서드 정의 위에 `@데코레이터명` 형태로 작성합니다.

```python
# 데코레이터 정의
def my_decorator(func):
    def wrapper():
        print('함수 실행 전')
        result = func()  # 원본 함수 호출
        print('함수 실행 후')
        return result
    return wrapper

# 데코레이터 적용
@my_decorator
def my_function():
    print('원본 함수 실행')

my_function()

```

**실행 결과:**

```text
함수 실행 전
원본 함수 실행
함수 실행 후

```
